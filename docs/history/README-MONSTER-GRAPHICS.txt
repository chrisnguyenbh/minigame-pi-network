# Gộp đồ họa quái vật

Đã lấy phần hữu ích từ code bạn gửi và gộp vào bản game hiện tại.

Giữ nguyên:
- 6 nhân vật chibi
- chọn nhân vật
- joystick mobile
- camera/map lớn
- hệ kỹ năng hiện tại
- Headshot / Xuyên / Lan
- nút gom tài nguyên 120s
- runtime fix

Thêm:

- Độc Nhện
- Boss Kiếm Ma Thủ Lĩnh

Không thay toàn bộ file bằng code bạn gửi vì code đó sẽ làm mất các chức năng mới của bản hiện tại.
