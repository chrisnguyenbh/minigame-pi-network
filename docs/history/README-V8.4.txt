Idle Defense v8.4 - Independent Auto Attack System
- Tower auto-attacks whenever enemies enter range.
- Hero auto-attacks independently at the same time.
- Tesla auto-targets and attacks on its own cooldown.
- Fireball auto-targets and attacks on its own cooldown.
- Module cooldown is not consumed when no target is present; it fires as soon as a valid enemy enters range.
- Future support modules should follow the same independent target/cooldown pattern.
