# Cân bằng tốc độ đánh / tốc độ quái

Đã chỉnh vì bản cũ có cảm giác quái áp sát nhanh hơn nhịp tấn công.

Tốc đánh cơ bản mới:
- Hỏa Nữ: 0.34 giây / đòn (~2.9 đòn/s)
- Phong Vân: 0.25 giây / đòn (4.0 đòn/s)
- Băng Tinh: 0.38 giây / đòn (~2.6 đòn/s)
- Thảo Linh: 0.42 giây / đòn (~2.4 đòn/s)
- Dược Sư: 0.36 giây / đòn (~2.8 đòn/s)
- Lôi Tướng: 0.45 giây / đòn (~2.2 đòn/s)

Quái thường:
- tốc độ cũ: 56–84
- tốc độ mới: 48–70
- scaling tối đa giảm nhẹ từ 1.40 xuống 1.35

Thân Pháp vẫn tiếp tục giảm thời gian hồi đòn.
